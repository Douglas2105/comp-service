# comp-service
Создать многофункциональный веб-сайт для жителей и гостей города Приморско-Ахтарск, предоставляющий полный спектр компьютерных услуг: от сборки игровых ПК до обучения пенсионеров. Главная цель: стать самым авторитетным и посещаемым ресурсом в городе по компьютерной тематике, который не только продаёт услуги, но и решает проблемы пользователей.
